# 📈 Bitcoin Price Tracker (MACOSX)

## Main technologies used
- [TypeScript](https://www.typescriptlang.org/)
- [Electron](https://www.electronjs.org/pt/)

## Commands
- `dev`: run your app 
- `build`: build your application

## Fetuares
- Starts with the operating system
- Fetch the dollar value of BTC every 30 seconds from Binance
- Notifies if the value is below or above the stipulated value.
